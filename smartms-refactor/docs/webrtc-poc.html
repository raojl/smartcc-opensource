智能呼叫中心 WebRTC 混合方案 PoC 验证报告

项目：SmartMS 呼叫中心（Asterisk 16.30） | 日期：2026-08-22  | 状态：验证通过PoC 完成
结论：浏览器 WebRTC 语音全链路打通 —— 浏览器（sip.js）通过 WSS 直连 Asterisk，DTLS-SRTP 加密媒体双向传输，回声测试通过。混合方案（WebRTC 语音 + IPC CTI 并行控制）架构验证成立，具备集成坐席工作台的工程条件。

一、背景与目标

现有呼叫中心坐席工作台依赖传统 SIP 软电话（插件/Flash 时代遗留），无法在现代浏览器直接使用。目标：

  • 坐席在浏览器内直接拨打/接听电话（无插件、无下载）
  • WebRTC 语音与既有 IPC CTI 控制通道并行，互不干扰（混合方案）
  • 信令加密（WSS）、媒体加密（DTLS-SRTP），符合安全要求

五、使用说明

  1. 导入 CA 证书：双击 smartms-ca.crt → 安装到「受信任的根证书颁发机构」（一次性）
  2. 浏览器打开 https:///webrtc-demo/（首次需授权麦克风）
  3. 点击「注册」→ 状态变「已注册（就绪）」
  4. 拨打 600 → 通话接通 → 对着麦克风说话 → 听到回声（验证双向媒体）
  5. 若听不到声音：点击「🔊 解锁播放」按钮（浏览器自动播放策略）

六、技术要点（配置摘要）

6.1 Asterisk WebRTC 关键配置

# pjsip.conf —— WebRTC 传输与分机（核心） [transport-wss] type=transport protocol=wss bind=0.0.0.0:8089 external_media_address= [3102] type=endpoint transport=transport-wss context=from-sipreg media_encryption=dtls ice_support=yes webrtc=yes dtls_cert_file=/etc/ssl/smartms-ca/asterisk.pem media_address= # 应答媒体地址=公网（关键） allow=ulaw,alaw,opus # rtp.conf —— 媒体端口与 NAT（核心） [general] rtpstart=10000 rtpend=20000 stunaddr=stun.l.google.com:19302 # ICE 公网 candidate 检测 external_rtp_address= # sip.conf —— 禁用 chan_sip 抢注 "sip" WS 协议（否则 PJSIP WS 加载失败） [general] websocket_enabled=no

6.2 浏览器（sip.js 0.16.1）要点

  • 用核心 API：UserAgent + Registerer + Inviter（SimpleUser 无 UMD 构建）
  • 远端音频播放：直接监听 peerConnection.ontrack（delegate.onTrack 在 0.16.1 不可靠）
  • 必须显式 constraints: { audio: true, video: false }（否则 SDP 带视频 m-line 导致 Asterisk 488）

七、关键排障档案（11 项）

现象根因修复
res_pjsip_transport_websocket 加载失败（declined）chan_sip 抢注 "sip" WS 协议，PJSIP 重复注册失败sip.conf 加 websocket_enabled=no
配置报 protocol=websocket 解析错误Asterisk 只认 ws 值pjsip.conf 改 protocol=ws
media_encryption=dtls_srtp 报错Asterisk 16 合法值为 dtls改 media_encryption=dtls
通话返回 500 Internal Errorendpoint transport 不支持逗号列表改单值 transport=transport-wss
通话返回 488 Not Acceptable编译无 SRTP（res_srtp.so 缺失）装 libsrtp2 + 重编 + 手动编译 res_srtp.so
pjproject 编译失败（os-auto.mak.in 缺失）GitHub tag 源码不含构建文件改用 Asterisk 官方 pjproject 包 + --with-external-srtp
通话无语音（媒体地址内网）应答 SDP 的 c= 是内网 172.17.0.7endpoint media_address=公网 IP
ICE Disconnected（无语音）Asterisk ICE candidate 只有内网 hostrtp.conf 配 stunaddr → 公网 srflx
移动网络单通对称 NAT 挡下行媒体家宽全锥 NAT 通过；移动场景后续上 TURN
通话通但无声音（浏览器）sip.js delegate.onTrack 不触发改用 peerConnection.ontrack 绑定播放
自动播放被浏览器拦截Chrome autoplay 策略「🔊 解锁播放」按钮（用户手势恢复）
